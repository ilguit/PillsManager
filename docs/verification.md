# Проверка первой версии

## Автоматически проверено

13 сентября 2026 года: `assembleDebug`, `assembleDebugAndroidTest`, `testDebugUnitTest` и `lintDebug` завершились успешно.

26 тестов на JVM/Robolectric прошли без ошибок:

- 12 JVM-тестов: статусы и границы 24 часов, несколько ежедневных времён, даты курса, инкрементальная генерация, устойчивые идентификаторы, снимки, часовые пояса, оба сезонных перехода и длительное отсутствие запуска.
- 6 тестов Room на Robolectric Android API 35: частичное досрочное подтверждение, повторное подтверждение, редактирование расписания, архивирование и отмена отметки, каскадное удаление выбранного профиля, исправление после 24 часов, курс с будущей датой начала.
- 3 теста уведомлений на Robolectric: приватный текст, объединение и частичное подтверждение, отсутствие повторов, сводка восстановления, очистка после удаления и отсутствие уведомлений о закрытых пропусках.
- 1 тест запуска MainActivity на Robolectric.
- 4 теста представления: сортировка каждого времени назначения, порядок между профилями, объединение только совпадающих времени и профиля, смешанные статусы и сохранение последних/следующих приёмов.

Lint: 0 ошибок; предупреждения об обновлениях зависимостей, использовании kapt и необязательных KTX-заменах. Версии зависимостей зафиксированы; автоматического обновления нет.

Отчёты создаются в `app/build/reports/tests/testDebugUnitTest/` и `app/build/reports/lint-results-debug.html`. Схема Room сохранена в `app/schemas/`.

Robolectric проверяет приложение на модели Android API 35, но не заменяет проверку реальной доставки сигналов системой.

## Проверка на устройстве

На указанном пользователем Pixel 7 Pro (192.168.0.14, Android 16 / API 36) итоговый APK установлен успешно. Прошли 9 инструментальных тестов Room и уведомлений, а также отдельный тест реальной доставки через AlarmManager: системный приёмник показал уведомление через 10 секунд при закрытом экране приложения.

Визуально проверены общая лента, раздельные карточки разных профилей при совпадении времени, цветные статусы принятой и ожидающей частей группы, порядок «09:00 Альфа → 09:00 Бета → 18:00 Альфа» и галочка справа. Тап по галочке открывает подтверждение; подтверждение архивирует тестовый курс. При проверке исправлен контраст системной строки в светлой теме.

Снимки экранов сохранены в `docs/screenshots/timeline.png` и `docs/screenshots/profiles.png`; протоколы — `docs/device-tests.txt` и `docs/physical-alarm-test.txt`.

Временные профили и тестовый пакет удалены после проверки. Реальные пользовательские данные не изменялись. На телефоне оставлено приложение с разрешёнными уведомлениями и точными напоминаниями. Длительный сон, перезагрузка и смена системного часового пояса на физическом телефоне не проверялись.

Для отдельного тестового устройства с Android 13+:

```sh
adb -s DEVICE_SERIAL install -r app/build/outputs/apk/debug/app-debug.apk
adb -s DEVICE_SERIAL install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s DEVICE_SERIAL shell am instrument -w com.palixander.pillsmanager.test/androidx.test.runner.AndroidJUnitRunner
```

Инструментальные тесты используют отдельную базу в памяти, но работают с каналом уведомлений приложения. Запускайте их на тестовой установке: они очищают уведомления и перепланируют сигнал.

Ручные сценарии:

1. Создать два профиля и по два препарата на совпадающее время. Проверить общую ленту, раздельные карточки профилей в порядке времени, раскрытие списка и уведомление каждого профиля.
2. Подтвердить часть группы, затем оставшуюся часть; проверить главную, историю и исчезновение уведомления. Повторный тап по старому уведомлению не меняет отметки.
3. Подтвердить ближайший приём заранее, проверить отсутствие уведомления в его назначенное время.
4. Оставить ожидающий приём до границы 24 часов; проверить перенос в историю. Исправить фактическое время и отменить отметку.
5. Изменить дозу и время после наступления приёма: ожидающая запись сохраняет старые данные, будущие используют новые.
6. Завершить курс, повторить его с новыми датами, удалить один профиль; другой профиль и его история сохраняются.
7. Отказать в уведомлениях и точных сигналах; проверить предупреждение, вернуть доступ через настройки. Закрыть приложение обычным способом и дождаться уведомления.
8. Перезагрузить телефон до приёма и после пропущенного времени; проверить восстановление расписания и одну сводку актуальных ожидающих.
9. Сменить часовой пояс телефона: время назначения остаётся исходным, на главной показаны оба времени при различии смещений.
10. Проверить светлую/тёмную тему, крупный системный шрифт, прокрутку форм с открытой клавиатурой и выбор даты/времени.

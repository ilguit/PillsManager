# Локализация

Резервный язык — английский. Тексты интерфейса, описания для TalkBack, статусы,
уведомления и сообщения ошибок на английском находятся в `app/src/main/res/values/strings.xml`.
Полные переводы находятся в каталогах `values-ru` (русский), `values-es` (испанский),
`values-pt-rBR` (бразильский португальский), `values-be` (белорусский)
и `values-uk` (украинский). Каждый каталог содержит формы множественного числа
своего языка. Для неподдерживаемых локалей используются английские тексты.

По умолчанию язык следует настройкам системы. На Android 13+ отдельный язык
можно выбрать в системных настройках приложения → «Язык». Список языков задан
в `res/xml/locales_config.xml` и подключён через `android:localeConfig` в манифесте.

## Добавление языка

1. Создайте `app/src/main/res/values-<код языка>/strings.xml` (например, `values-en`).
2. Добавьте BCP-47 код языка в `res/xml/locales_config.xml`. Переведите строки и `plurals`, сохранив имена ресурсов и позиционные параметры
   `%1$s`, `%2$s`, `%1$d`. Их можно переставлять, но нельзя менять типы.
   Переводите целые предложения; имена профилей, препаратов и дозы вводит пользователь.
3. Для `plurals` задайте формы нужного языка, обязательно `other`.
   `active_courses` — количество активных курсов профиля;
   `medicines_now` — количество препаратов в карточке текущего приёма.
4. Проверьте приложение с новым языком системы: навигацию, длинные строки,
   диалоги, TalkBack, уведомления, ошибки импорта и количества
   0, 1, 2, 5, 11, 21, 22, 25, 111. Для RTL проверьте направление и иконки переходов.
5. Запустите `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`.

В debug-сборке включены псевдолокали Android `en-XA` (удлинение текста) и
`ar-XB` (RTL). Они доступны через настройки языка в режиме разработчика.
Стрелки навигации по неделям автоматически отражаются при RTL.

В Compose ресурсы берутся из `LocalResources.current`, чтобы учитывать текущую
конфигурацию. В обычном Android-коде используется `Context.getString`.
Сообщения исключений не показываются напрямую: слой данных возвращает
`ValidationError`, а `Localization.kt` сопоставляет его с ресурсом.
Не переводите идентификаторы статусов, ключи JSON, даты и время хранения.

Даты для чтения форматируются с локалью ресурсов. Выбор времени учитывает
системную настройку 12/24 часа. Поля ручного ввода дат курса пока используют
ISO `ГГГГ-ММ-ДД`, а поле исправления фактического времени — `ДД.ММ.ГГГГ ЧЧ:ММ`;
подписи явно показывают формат. При переводе этих подписей сохраните порядок
компонентов. Кнопки выбора даты и времени позволяют обойти ручной ввод.

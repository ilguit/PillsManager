# Локальные данные без восстановления

Первая версия предназначена для личного использования на одном телефоне, где один пользователь ведёт несколько профилей. Данные хранятся только в Room; регистрация, сервер, синхронизация, экспорт, облачное резервное копирование и перенос системой отключены. Это уменьшает сложность и исключает передачу истории лекарств, но потеря телефона или удаление данных приложения означает потерю истории; последующая синхронизация потребует отдельного протокола разрешения конфликтов.

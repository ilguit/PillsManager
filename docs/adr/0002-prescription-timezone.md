# Исходный часовой пояс назначения

Ежедневное расписание привязано к часовому поясу, действующему при создании назначения, и не переезжает вместе с телефоном. Пользователь выбрал сохранение исходного времени вместо времени по месту пребывания; интерфейс показывает местное время и исходное при различии смещений. Храним идентификатор зоны, а не только смещение: при сезонном переходе несуществующее время сдвигается вперёд на величину перехода, повторяющееся время создаёт один приём при первом наступлении.

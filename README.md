# PillsManager / Лекарства

Локальное Android-приложение для ежедневного расписания лекарств нескольких людей. Android 13+ (API 33), Kotlin, Compose Material 3, Room и AlarmManager. Без сетевого доступа, аккаунтов и резервного копирования.

Идентификатор приложения: `com.palixander.pillsmanager`. При переходе с `ru.pillsmanager` Android устанавливает отдельное приложение; данные прежней установки автоматически не переносятся.

## Сборка и установка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0; Gradle 8.13 скачивается wrapper-скриптом. Укажите SDK через `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties`. Путь к JDK задаётся через `JAVA_HOME`.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это подписанная отладочным ключом сборка для личной установки. Для обновлений с сохранением данных используйте ту же подпись; сохраняйте свой ключ сборки. Публичная публикация и release-подпись не настроены.

На телефоне можно открыть APK через файловый менеджер, разрешив установку из этого источника. При первом запуске создайте профиль, добавьте назначение и разрешите уведомления и точные напоминания через карточку на главной. Если Android больше не показывает запрос уведомлений после отказов, включите их в системных настройках приложения.

## Использование

- «Ближайшее»: общая лента ожидающих, последних принятых и ближайших приёмов по возрастанию назначенного времени. Карточка объединяет только совпадающие время и профиль; внутри препараты идут по названию. Цветные подписи показывают статус, включая частичное подтверждение группы.
- «Профили»: имя и ежедневные приёмы, отсортированные сначала по времени, затем по названию. Назначение с несколькими временами отображается отдельной строкой для каждого времени. Галочка справа завершает весь курс после подтверждения; «Изменить» редактирует назначение целиком. Время вводится через запятую, например `09:00, 18:00`; даты — `2026-09-13`. Окончание необязательно и включает последний день.
- Тап по уведомлению открывает все ожидающие на это время профили. В каждом профиле можно раскрыть препараты и отметить приём отдельно; все профили можно отметить одной кнопкой. После подтверждения всех профилей экран закрывается. Ближайший приём доступен для досрочного подтверждения.
- «История»: фильтр по профилю, исправление отметок и фактического времени, отмена отметки.
- Через 24 часа ожидающий приём автоматически считается пропущенным. Изменения расписания затрагивают только будущие неподтверждённые приёмы; история сохраняет прежние название и дозу.
- Галочка справа архивирует курс и отменяет будущие и ожидающие приёмы. «Повторить курс» создаёт новый. Удаление профиля полностью удаляет его данные после подтверждения.

## Напоминания

Уведомления объединяются по назначенному моменту для всех профилей; содержат только «Пора принять лекарства». Системный сигнал планируется на ближайшее событие, после него расписание продлевается. Просроченные уведомления очищаются, повторная доставка предотвращается отметкой в базе. Перезагрузка восстанавливает расписание и создаёт одно сводное уведомление об ожидающих приёмах.

Без доступа к точным сигналам используется неточный системный сигнал и отображается предупреждение; без разрешения уведомлений остаётся расписание в приложении. Android может задерживать фоновые сигналы, особенно при энергосбережении; принудительная остановка приложения через системные настройки требует его повторного открытия. Работа на конкретном телефоне должна быть проверена отдельно. API: [точные напоминания Android](https://developer.android.com/develop/background-work/services/alarms).

## Проверки

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug
# При подключённом Android 13+ или эмуляторе:
./gradlew :app:connectedDebugAndroidTest
```

`ScheduleTest` проверяет границы 24 часов, часовые пояса и DST, ежедневную генерацию, сохранение снимков, курс и повторяемость идентификаторов. `RepositoryTest` проверяет Room-транзакции, частичное подтверждение, идемпотентность, редактирование курса, каскадное удаление, архивирование и исправления истории.

Дополнительный ручной чек-лист и результаты запуска — в `docs/verification.md`. Словарь — `CONTEXT.md`, решения — `docs/adr/`.
